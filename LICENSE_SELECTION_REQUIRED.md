# License selection required before public release

No license has been assigned automatically because this is a legal decision
for the authors and institution.

A common publication-friendly split is:

- source code: MIT or BSD-3-Clause;
- released data and figures: CC BY 4.0;
- trained model weights: explicitly state whether the code or data license
  applies;
- third-party YOLO/Ultralytics components: retain their upstream license and
  attribution requirements.

Replace this file with the selected license texts and add a short license map
to the main README before making the GitHub repository public.
